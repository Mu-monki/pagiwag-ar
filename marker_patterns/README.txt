Place your compiled MindAR target file (`stickers.mind`) and borderless sticker artwork (.png/.jpg) here.

NO BLACK BORDERS & NO .fset/.iset TRIPLETS REQUIRED!
MindAR compiles all of your teammates' borderless sticker designs into a single `stickers.mind` bundle in ~2 seconds.

Step-by-Step MindAR Compilation:
1. Open the browser-based MindAR Image Target Compiler:
   https://hiukim.github.io/mind-ar-js-doc/tools/compile
2. Drag and drop all of your teammates' borderless sticker PNGs in order:
   - Target Index 0: pagtanow.png
   - Target Index 1: talampad.png
   - Target Index 2: gameon.png
   - Target Index 3: kabataan.png
   (Add any additional stickers as Index 4, 5, etc.)
3. Click "Start", wait ~2 seconds, and click "Download compiled".
4. Save the downloaded file as:
   marker_patterns/stickers.mind
5. Save the individual borderless sticker PNGs here (e.g., marker_patterns/pagtanow.png) so they appear in the 3D Simulator and Borderless Sticker Kit.
